ติดตั้งบนมือถือ (เพิ่มไปหน้าจอโฮม)

ทำครั้งเดียว จะได้ไอคอนแอปบนหน้าจอโฮม เปิดใช้เหมือนแอปจริง และเปิดรับการแจ้งเตือนได้ (โดยเฉพาะ iPhone ที่ต้องติดตั้งก่อนถึงจะแจ้งเตือนได้)

Android (Chrome)

แตะ “ติดตั้ง” — เสร็จแล้ว

สัญลักษณ์ในแอป

ไอคอนหลักที่เจอในหน้าแอป และหน้าที่ของแต่ละปุ่ม

ปักหมุดโปรด

กดดาวบนการ์ดเอกสาร จะลอยขึ้นบนสุดของรายการ

เมนู ⋯

แก้ไข / ตั้งวันแจ้งเตือนล่วงหน้า / ลบเอกสาร

แจ้งเตือน

กดเปิดครั้งแรกต้องอนุญาตเบราว์เซอร์ — ถ้าไม่เด้งป๊อปอัป ให้ดูไอคอนเล็กๆ ขวาแถบ URL

สลับธีม

โหมดมืด/สว่าง จำค่าล่าสุดที่เลือกไว้อัตโนมัติ

ค้นหา / กรอง

ค้นชื่อ ผู้ออก หรือหมายเลขเอกสาร กรองตามสถานะและหมวด

เพิ่มเอกสาร

กรอกข้อมูลเอกสารใหม่ 24 ประเภทให้เลือก

ส่งออกข้อมูล

บันทึกเป็นไฟล์ JSON สำรองไว้ หรือย้ายไปเปิดเครื่องอื่น

นำเข้าข้อมูล

เลือกไฟล์ JSON ที่เคยส่งออกไว้ เพื่อดึงข้อมูลกลับ

ส่งออกปฏิทิน

ได้ไฟล์ .ics ใส่ปฏิทินมือถือ เตือนวันหมดอายุล่วงหน้า

จำไว้เสมอ

สำรองข้อมูลเป็นระยะ — ข้อมูลหลักเก็บอยู่ในเบราว์เซอร์/อุปกรณ์เครื่องนั้นๆ (หรือในคลาวด์ถ้าเปิดซิงก์) กด “ส่งออกข้อมูล” เก็บไฟล์ JSON ไว้กันลืม/กันเครื่องพังเป็นระยะๆ อยู่ดี

เปิดแอปเป็นระยะให้ระบบเช็ก — การแจ้งเตือนทำงานตอนเปิดแอป ไม่ใช่ push จากเซิร์ฟเวอร์กลางแบบอีเมล ถ้าไม่ได้เปิดนานๆ อาจพลาดแจ้งเตือน

เปิดซิงก์ข้อมูลข้ามอุปกรณ์ได้แล้ว — กดไอคอนรูปเมฆที่แถบบนสุด สมัครสมาชิกด้วยอีเมล+รหัสผ่านครั้งเดียว แล้วเข้าสู่ระบบด้วยบัญชีเดียวกันบนคอมและมือถือ ข้อมูลจะซิงก์ให้อัตโนมัติทันทีที่แก้ไข
