# LifeDoc Guard

ระบบบริหารและแจ้งเตือนวันหมดอายุเอกสารสำคัญของบุคคล — เก็บข้อมูลทั้งหมดใน**เครื่องของคุณเท่านั้น** (localStorage) ไม่มีเซิร์ฟเวอร์ ไม่มีค่าใช้จ่าย และไม่มีการส่งข้อมูลออกไปที่ไหนทั้งสิ้น

สร้างด้วย React + TypeScript + Vite + Tailwind CSS + shadcn/ui-style components (Radix UI primitives) และ `lucide-react`

## ฟีเจอร์หลัก

- แดชบอร์ดสไตล์ Bento Grid พร้อม Dark/Light mode (ค่าเริ่มต้น: Dark)
- เทมเพลตเอกสาร 24 ประเภทครอบคลุมทุกด้านของชีวิต (ตัวตน, ยานพาหนะ, สุขภาพ, การเงิน, วิชาชีพ, ดิจิทัล)
- คำนวณวันคงเหลือ / เปอร์เซ็นต์อายุการใช้งาน / สถานะ (ปกติ, ใกล้หมดอายุ, ด่วน, วิกฤต) แบบอัตโนมัติ
- ค้นหา, กรองตามหมวดหมู่/สถานะ, จัดเรียงหลายรูปแบบ
- ปกปิดหมายเลขเอกสารที่ละเอียดอ่อน (มีปุ่มแสดง/ซ่อน)
- แนบไฟล์/รูปถ่ายเอกสาร (เก็บเป็น Base64 ในเครื่อง)
- ส่งออก/นำเข้าข้อมูลสำรองเป็นไฟล์ JSON
- ส่งออกเป็นไฟล์ปฏิทิน `.ics` (นำเข้า Google Calendar / Apple Calendar / Outlook ได้ทันที พร้อมการแจ้งเตือนล่วงหน้าตามที่ตั้งไว้)
- ติดตั้งเป็นแอปบนมือถือได้ (PWA) — ใช้งานได้แบบออฟไลน์หลังโหลดครั้งแรก

## เริ่มต้นใช้งาน

ต้องติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไปก่อน

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ไปที่ลิงก์ที่ปรากฏ (ปกติคือ `http://localhost:5173`)

## ใช้งานบนมือถือ (ฟรี ไม่มีค่าใช้จ่าย)

มี 2 วิธีหลัก:

### วิธีที่ 1: เข้าถึงผ่าน Wi-Fi วงเดียวกัน (เร็วที่สุด ไม่ต้องตั้งค่าอะไรเพิ่ม)

1. รันแอปด้วย `npm run dev` บนคอมพิวเตอร์ (ต่อ Wi-Fi วงเดียวกับมือถือ)
2. เทอร์มินัลจะแสดง URL แบบ `Network: http://192.168.x.x:5173` — เปิดลิงก์นี้บนเบราว์เซอร์มือถือ
3. กด "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) เพื่อให้ใช้งานเหมือนแอปจริง (รองรับ PWA)

### วิธีที่ 2: Deploy ขึ้นโฮสติ้งฟรี เพื่อเข้าถึงได้ทุกที่

โปรเจกต์นี้เป็น static site ล้วน ๆ (ไม่มี backend) จึงฝากได้ฟรีบนบริการเหล่านี้:

- **Vercel** (`vercel.com`) — เชื่อม GitHub repo แล้ว deploy อัตโนมัติ
- **Netlify** (`netlify.com`) — ลาก-วางโฟลเดอร์ `dist/` หลัง `npm run build` หรือเชื่อม Git
- **Cloudflare Pages** (`pages.cloudflare.com`)
- **GitHub Pages**

ทุกบริการด้านบนมีแผนฟรีที่เพียงพอสำหรับแอปนี้ (ไม่มีฐานข้อมูล ไม่มี API เรียกเก็บเงิน)

```bash
npm run build   # ได้ไฟล์ static ในโฟลเดอร์ dist/
```

> หมายเหตุ: เนื่องจากข้อมูลเก็บใน localStorage ของแต่ละเบราว์เซอร์ ข้อมูลบนมือถือกับคอมพิวเตอร์จะ**ไม่ sync กันอัตโนมัติ** — ใช้ฟีเจอร์ "ส่งออกข้อมูล (JSON)" แล้ว "นำเข้าข้อมูล (JSON)" อีกเครื่องเพื่อย้ายข้อมูล

## โครงสร้างโปรเจกต์

```
src/
  types.ts              โครงสร้างข้อมูลหลัก (DocumentItem, CategoryId, DocumentStatus)
  data/
    docTypeCatalog.ts    เทมเพลตเอกสาร 24 ประเภท
    mockData.ts           ข้อมูลตัวอย่างเริ่มต้น (12 รายการ)
  lib/
    utils.ts              คำนวณวันคงเหลือ/สถานะ/มาส์กข้อมูล
    storage.ts             อ่าน/เขียน localStorage, สำรอง/กู้คืนข้อมูล
    ics.ts                 สร้างไฟล์ .ics
    icon-map.tsx           แมปชื่อไอคอนเป็นคอมโพเนนต์ lucide-react
  hooks/
    useDocuments.ts        state หลักของเอกสารทั้งหมด + CRUD
    useTheme.ts             จัดการ Dark/Light mode
  components/
    ui/                    shadcn/ui-style primitives (Button, Dialog, Select, ...)
    Header.tsx, SummaryCards.tsx, Toolbar.tsx, DocumentGrid.tsx,
    DocumentCard.tsx, DocumentFormDialog.tsx, ConfirmDialog.tsx, EmptyState.tsx
```

## ความเป็นส่วนตัว

- ไม่มีการเรียก API ภายนอกใด ๆ เพื่อส่งข้อมูลเอกสารของคุณ ข้อมูลทั้งหมดอยู่ใน `localStorage` ของเบราว์เซอร์บนเครื่องคุณเท่านั้น
- หมายเลขเอกสารที่ทำเครื่องหมาย "ปกปิด" จะแสดงผลแบบมาส์ก (`••••1234`) จนกว่าจะกดปุ่มแสดง
- แนะนำให้กด "ส่งออกข้อมูล (JSON)" เก็บสำรองไว้เป็นระยะ เพราะข้อมูลผูกกับเบราว์เซอร์/เครื่องที่ใช้งาน หากล้างแคชเบราว์เซอร์ข้อมูลจะหายไป
